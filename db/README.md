# Database Files

This folder is grouped by purpose:

- `sql/` - migration, cleanup, seed, and production SQL scripts.
- `imports/` - CSV and XLSX files used for imports or source data.
- `docs/` - notes, guides, PDFs, and Word documents related to database/data work.
- `assets/` - images or other supporting binary assets.
- `bin/` - full database dumps and generated structure/data exports.

Add new dated SQL scripts to `sql/`.
